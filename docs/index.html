🖼 Multi-Image Canvas

多圖片畫布展示器

在一個畫布上展示所有圖片

支援滑鼠滾輪縮放、自由拖曳、圖片縮放刪除與工作區儲存，適合設計師、攝影師與創作者。

⬇ 下載最新版本

🔍 畫布 Zoom

滑鼠滾輪縮放整個畫布，以游標為中心點縮放，範圍 0.05× 到 10×。

🖱 自由拖曳

匯入後自動網格排列，之後可任意拖曳圖片到畫布上的任何位置。

📐 個別縮放

點選單張圖片，在側邊面板放大（×1.2）或縮小（÷1.2），最大 10×。

🔒 工作區鎖定

一鍵鎖定，防止誤觸移動圖片，鎖定時仍可平移和縮放畫布。

💾 工作區儲存

儲存為 .mwp 檔案，保留所有圖片位置與縮放狀態，下次直接載入繼續。

📁 批量匯入

支援檔案對話框選取或拖放資料夾，一次匯入多張圖片自動排列。
